# ЛИНЕЙНЫЙ КЛАССИФИКАТОР ДЛЯ КРЕДИТНОГО СКОРИНГА
Этот демонстрационный проект показывает реализацию простого классификатора с L2-регуляризацией для бинарной классификации кредитных заявок. Проект включает генерацию синтетических данных, предобработку, обучение модели и оценку её качества.

## Сгенерированные данные содержат следующие признаки:
- **Age** – возраст заявителя (18–75 лет)
- **Income** – годовой доход (тыс. долларов)
- **Credit_score** – кредитный рейтинг (300–850)
- **Loan_amount** – запрашиваемая сумма кредита
- **Approved** – целевая переменная: 1 (одобрено) или -1 (отклонено)

## Пайплайн обработки данных
1. Обработка числовых признаков:
  Замена пропусков средним значением
  Стандартизация (StandardScaler)
2. Обработка категориальных признаков:
  Замена пропусков наиболее частым значением
  One-Hot Encoding
3. Объединение преобразований через ColumnTransformer
4. Обучение перцептрона

## Структура проекта:
/linear_classifier
├── classification.py # Основной скрипт: модель, пайплайн, обучение и оценка
├── data_generation.py # Генерация синтетических данных о кредитных заявках
